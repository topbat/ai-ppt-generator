# 企业模板下的视觉构图升级设计

> 日期：2026-08-17
> 状态：设计已确认
> 范围：主生成流水线（“新建生成”），不改变独立 ppt-master 流水线

## 1. 目标

在继续满足企业模板、精确页数、事实可追溯、可编辑 PPTX、可重试和低成本等要求的前提下，显著降低固定版式造成的页面重复感，提升整册连贯性、主次层级和关键页面的视觉表现。

本次设计优先解决：

1. 同一套企业模板中正文页面构图重复；
2. 页面逐页正确，但全册缺少统一的视觉概念和节奏；
3. 容器边距、字体、层级和内容容量缺少统一的硬性门槛；
4. 少数高价值页面受固定版式限制，无法形成视觉高潮。

## 2. 已确认的产品决策

- 采用“模板外壳固定、正文安全区受控自由”的模板保真等级；
- Logo、页眉页脚、页码、背景和品牌装饰作为不可移动层；
- 保持模板字体族，字号、行距、字重和段落间距按语义角色动态计算；
- 内容放不下时，保留结论和事实，压缩次要解释，将支持性细节移入讲者备注；
- 自由设计 Agent 自动选择正文页的约 15%～20%，最多 5 页；
- 极速模式保持现状；标准模式启用艺术指导、视觉分镜和布局语法；专业模式在此基础上增加关键页自由设计 Agent。

## 3. 非目标

- 不把主生成流水线整体改造成 ppt-master；
- 不允许自由设计 Agent 改写事实、数字、页数和核心结论；
- 不以无限缩小字体解决内容溢出；
- 不破坏模板 Logo、页眉页脚、品牌字体和配色；
- 不要求所有页面都使用自由 SVG 构图；
- 第一阶段不引入用户手工拖拽编辑器。

## 4. 总体架构

主流水线调整为：

```text
VALIDATE
→ PARSE_DOC || PARSE_TPL
→ KNOWLEDGE
→ FACT_CHECK
→ OUTLINE
→ PLAN
→ ART_DIRECTION
→ STORYBOARD
→ CONTENT
→ MATCH
→ COMPOSE
→ LAYOUT_GUARD
→ KEY_SLIDE_DESIGN（仅专业模式）
→ RENDER
→ DECK_GUARD
→ BEAUTIFY
→ CONVERT
→ QA / REPAIR
→ PUBLISH
```

新增阶段保持软依赖：任何新增能力失败，都必须能够回退到现有稳定渲染链路，不能因视觉增强失败而导致整册任务失败。

### 4.1 ART_DIRECTION

根据模板 Design Token、目标受众、模式、内容密度和整册大纲，生成统一的视觉方向。

输出包括：

- 整册视觉概念；
- 不可变品牌规则；
- 页面密度节奏；
- 视觉母题；
- 主辅色使用比例；
- 字体层级；
- 图片和图表策略；
- 各章节的视觉差异策略。

### 4.2 STORYBOARD

为每一页确定：

- 叙事角色；
- 重要程度；
- 主结论；
- 第一视觉焦点；
- 布局家族；
- 视觉重量方向；
- 内容容量；
- 与前后页的承接关系；
- 是否为自由设计候选页。

### 4.3 COMPOSE

在模板正文安全区内，通过布局语法选择和实例化 Layout Recipe，不再由一个页面类型绑定一套固定坐标。

### 4.4 LAYOUT_GUARD

在渲染前统一检查页面边界、保护区、容器四边距、字体、重叠、内容容量和层级。

### 4.5 KEY_SLIDE_DESIGN

仅专业模式启用。对少量关键页执行受限自由构图，并保留普通构图版本作为回退。

### 4.6 DECK_GUARD

检查整册连贯性、布局重复度、视觉节奏、章节区分、标题承接和主次关系。

## 5. 模板空间契约

模板解析器除现有页面角色和 Design Token 外，应输出模板空间契约。

```json
{
  "safe_zone": {"x": 0.8, "y": 1.4, "w": 11.7, "h": 5.3},
  "protected_zones": [
    {"role": "logo", "x": 11.8, "y": 0.2, "w": 1.0, "h": 0.5},
    {"role": "footer", "x": 0.0, "y": 7.1, "w": 13.33, "h": 0.4}
  ],
  "grid": {"columns": 12, "gutter": 0.24},
  "brand_rules": {
    "primary": "1B3A6B",
    "accent": "2F80ED",
    "font_title": "Microsoft YaHei",
    "font_body": "Microsoft YaHei"
  }
}
```

模板页被拆为三层：

1. Locked Layer：Logo、页眉页脚、页码、背景和品牌装饰；
2. Flexible Content Zone：标题安全区、正文安全区、栅格和禁入区域；
3. Generated Layer：文本、图片、图表、卡片和强调图形。

无法可靠识别正文区时，使用模板页面几何与系统安全边距求交；仍不可靠时回退现有 content frame 逻辑。


有效内容区等于外部区域减去上、右、下、左四个内边距。所有文字、图片、图表和子容器只能进入有效内容区。

## 7. 布局语法

布局引擎提供可组合的家族，而不是继续无限增加固定页面类型：

- 单焦点：大标题、大数字、核心结论；
- 双区域：左右分栏、图文、结论与证据；
- 多区域：卡片、指标、对比；
- 流程型：时间轴、步骤、路线图；
- 结构型：架构、组织关系、分层模型；
- 数据型：主图表、图表加结论、仪表盘；
- 编辑型：非对称留白、引用、主视觉图片。

Layout Recipe 可以确定性地产生左右镜像、深浅背景、焦点位置、标题宽度和元素比例等变体。变体选择必须由内容适配度和全册节奏驱动，不允许纯随机。

布局选择评分：

```text
内容适配度        40%
与前后页差异度    25%
企业模板适配度    20%
全册节奏贡献      15%
```

## 8. 字体与层级

字体族继承模板，字号按角色动态计算：

| 角色 | 建议范围 | 约束 |
|---|---:|---|
| 封面标题 | 32–48pt | 最多两行 |
| 章节标题 | 28–40pt | 必须形成章节切换感 |
| 页面标题 | 24–32pt | 基线和视觉规则全册一致 |
| 核心结论 | 22–30pt | 每页最多一个 |
| 正文 | 16–22pt | 默认不得低于 16pt |
| 图表标签 | 12–16pt | 按阅读距离和数据密度计算 |
| 注释/来源 | 10–13pt | 仅用于辅助信息 |

Typography Guard 检查：

- 正文字号低于下限；
- 同页字体层级超过四级；
- 标题与正文缺少显著差异；
- 同级元素字号、字重或颜色不一致；
- 同页高强调元素超过两个；
- 行数、行长、行距和段落间距超过预算；
- 文本异常截断或标点断裂。

## 9. 内容容量与讲者备注

内容适配顺序固定为：

```text
1. 更换布局配方
2. 调整栏宽和容器比例
3. 在 Token 范围内压缩间距
4. 压缩次要解释
5. 将 supporting 内容移入讲者备注
6. 在角色范围内微调字号
7. 回退为更简单的稳定版式
```

进入讲者备注的内容必须保留来源：

```json
{
  "visible_content": {
    "conclusion": "统一数据底座是转型前提",
    "evidence": ["数据标准不统一", "系统间接口复杂"]
  },
  "speaker_notes": {
    "details": ["原材料中的详细解释"],
    "sources": [{"document_id": "doc_x", "pages": [12, 13]}]
  }
}
```

压缩前后必须校验：

- 数字集合一致；
- 专有名词不丢失或替换；
- 主结论语义不变化；
- 来源页不变化；
- 不增加原文不存在的新事实；
- 已移入备注的细节不在页面重复出现。

## 10. 连贯性与重复度控制

每页生成布局指纹：

```text
布局家族 + 主焦点位置 + 区域数量 + 背景明暗
+ 图片占比 + 图表占比 + 标题位置 + 视觉重量方向
```

硬规则：

- 相邻页面布局指纹不能相同；
- 同一布局家族不能连续出现；
- 同一章节最多两次使用相同布局家族；
- 连续三页的第一视觉焦点位置必须变化；
- 卡片型页面不得超过正文页的 30%；
- 每章至少有一个低密度强调页；
- 数据页之后优先安排解释页或结论页；
- 每页只能有一个第一视觉焦点；
- 页面标题、主结论和过渡语必须能承接前后页。

Deck Guard 同时检查章节内部和整册叙事：

```text
页面主结论
├─ 核心证据或数据
├─ 次要解释
└─ 来源及辅助信息
```

`importance=primary|secondary|supporting` 决定元素面积、字号、颜色、位置和是否进入讲者备注。

## 11. 关键页自由设计 Agent

选择数量：

```text
selected = min(5, ceil(正文页数 × 0.18))
```

附加限制：

- 少于 8 个正文页时最多选择 1 页；
- 同一章节最多选择 1 页；
- 连续两页不能同时进入自由设计；
- 没有足够高价值候选页时允许少选；
- 封面、目录和普通章节页默认不占额度。

选择评分：

```text
业务重要性          35%
页面结构复杂度      20%
视觉高潮需求        20%
普通布局满意度不足  15%
全册节奏贡献        10%
```

Agent 输入仅包含：

- 冻结后的标题、结论、数字和正文；
- 模板正文安全区和保护区；
- 企业字体和色板；
- 允许使用的组件；
- 四边距和最小字号；
- 前后页面的视觉摘要。

Agent 输出受限 SceneSpec 或受限 SVG。输出必须通过：

1. 内容哈希比对；
2. 数字和专有名词比对；
3. 四边距、保护区、重叠和越界检查；
4. 字体、层级和第一焦点检查；
5. 可编辑性检查；
6. 截图视觉复评。

允许最多两次定向修复。仍不合格时使用已保存的普通布局版本。

## 12. 模式分层

### 极速模式

保持现有路径，不增加新的 LLM 调用和 Agent 成本。可复用纯规则的 Box Model 和 Typography Guard，但不能因此增加明显耗时。

### 标准模式

启用：

- ART_DIRECTION；
- STORYBOARD；
- 布局语法和 Layout Recipe；
- Box Model、Typography Guard；
- Deck Rhythm Guard；
- 内容压缩和讲者备注。

不启用自由设计 Agent。

### 专业模式

在标准模式能力上增加：

- KeySlideSelector；
- 少量关键页自由设计 Agent；
- Vision Critic；
- 关键页两轮定向修复；
- 更严格的整册视觉质量门。

## 13. 错误处理与回退

新增能力的失败处理：

```text
自由设计 Agent 版本
→ Agent 第二次定向修复
→ 同页约束式布局版本
→ 通用稳定版式
```

- 艺术指导输出异常：根据模板 Token 生成默认策略；
- 分镜缺页：根据页面类型和章节位置确定性补齐；
- 布局配方不适配：尝试下一候选配方；
- 四边距或字体不合格：重新构图，不带病进入渲染；
- 连贯性异常：仅修正标题、过渡语和次要解释；
- Agent 超时、无产物或修改事实：丢弃 Agent 版本；
- 所有增强版本失败：回退当前系统渲染器。

新增阶段均保存 Checkpoint，使重试不重复消耗已完成的艺术指导、分镜和 Agent 结果。

## 14. 验收指标

| 指标 | 硬性目标 |
|---|---:|
| 页面边界或保护区越界 | 0 |
| 容器四边距违规 | 0 |
| 正文字号低于 16pt | 0 |
| 文本溢出或异常截断 | 0 |
| 未经核验数字变化 | 0 |
| 相邻页面布局指纹重复 | 0 |
| 单一布局家族占正文页比例 | ≤30% |
| 连续三页焦点位置完全相同 | 0 |
| 每页第一视觉焦点数量 | 1 |
| 关键页 Agent 失败后无回退 | 0 |
| 目标页数偏差 | 0 |

软性目标：

- 整册视觉分相对当前标准模式提升；
- Deck Rhythm Score 达到预设阈值；
- 标准模式新增耗时控制在可接受范围；
- 专业模式自由设计页的采纳率可观测；
- 模板品牌元素像素级保持稳定。

## 15. 测试策略

### 15.1 单元测试

- Box Model 有效内容区；
- 真实字体文本测量；
- 四边距、保护区和重叠检测；
- 布局指纹和重复度；
- 内容哈希、数字和专有名词比对；
- 关键页选择数量和章节分布；
- 各级回退路径。

### 15.2 属性测试

随机生成不同长度、不同元素组合的页面内容，验证：

- 不越界；
- 不低于最小字号；
- 不进入保护区；
- 不产生未声明重叠；
- 内容溢出最终可以通过换布局、压缩、备注或回退收敛。

### 15.3 黄金样例

维护多套真实企业模板和固定材料，比较：

- 页面截图；
- 品牌层像素稳定性；
- 布局家族分布；
- 视觉分和节奏分；
- 事实、来源和页数；
- 讲者备注内容。

### 15.4 模板压力测试

- 标题带很窄；
- Logo 占据正文边缘；
- 深色背景；
- 4:3 画布；
- 大页脚；
- 字体缺失；
- 正文安全区不规则；
- 模板装饰与内容区重叠。

### 15.5 端到端测试

覆盖极速、标准、专业三种模式，以及新增阶段 Checkpoint、重试、Agent 超时、Agent 修改事实、视觉校验失败和全链路回退。

## 16. 分阶段交付

### 第一阶段：企业模板与确定性构图

- 模板空间契约；
- Box Model；
- Typography Guard；
- Layout Recipe 基础设施；
- 重复度指纹和 Deck Guard；
- 现有版式适配布局语法。

### 第二阶段：整册设计能力

- ART_DIRECTION；
- STORYBOARD；
- 20～30 个首批 Layout Recipe；
- 内容容量、压缩和讲者备注；
- 标准模式接入。

### 第三阶段：专业模式关键页

- KeySlideSelector；
- 受限 SceneSpec/SVG；
- Agent 内容锁定；
- 可编辑输出；
- Vision Critic 和两轮修复；
- 专业模式接入。

### 第四阶段：优化与扩展

- 图片素材管线；
- 企业 Style Pack；
- 更多布局家族；
- 用户偏好反馈；
- 视觉质量、耗时和 Agent 成本监控。

## 17. 建议实施原则

先完成确定性基础，再引入 Agent：

1. 四边距、字体和保护区必须先成为全模式统一规则；
2. 布局语法和回退路径稳定后，再增加艺术指导和视觉分镜；
3. 标准模式稳定后，再在专业模式中启用关键页 Agent；
4. Agent 永远是视觉增强器，不是事实和内容的所有者；
5. 任意增强能力都必须满足“失败不影响交付”。
