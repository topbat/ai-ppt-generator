# 套用我的模板：5 份可编辑 PPTX

这些文件用于在 main-ppt 的“ppt-master 生成”页面中选择“套用我的模板生成”后，上传到模板文件区域。正文资料应在材料区域另外提供。

## 模板选择

| 文件 | 适用场景 |
| --- | --- |
| 01_经营分析_深蓝_填充模板.pptx | 月度或季度经营汇报、业务分析 |
| 02_项目方案_墨绿_填充模板.pptx | 项目提案、实施方案、里程碑计划 |
| 03_产品介绍_紫黑_填充模板.pptx | 产品介绍、客户演示、解决方案 |
| 04_培训教学_暖橙_填充模板.pptx | 内部培训、知识讲解、练习反馈 |
| 05_工作总结_朱红_填充模板.pptx | 部门总结、阶段复盘、下期安排 |

每份 8 页、16:9：封面、目录、章节页、双栏内容页、原生图表页、原生表格页、图文页、结束页。各页是可复用的版式样例，目录章节可按实际材料更新，内容页可复制使用。页数输入框应与最终期望页数一致，模板有 8 页并不表示只能生成 8 页。

## 使用方法

1. 选择“套用我的模板生成”，在模板区域上传其中一份 PPTX。
2. 单独提供真实的正文资料、数据和图片，避免把模板示例当作业务资料。
3. 视觉风格选择跟随上传模板的选项；画布选择 PPT 16:9。
4. 页数填写希望生成的总页数，包含封面与结束页。首次试用可填写 8。
5. 按需要选择讲者备注、旁白或动画。模板本身不附带音频和动画。
6. 如有图片资料，在附加要求中明确优先使用上传图片；需要新配图时，再选择图库或 AI 生图。

## 可直接填写的附加要求

> 以提供的 PPTX 为版式模板，保留统一配色、字体、背景及主要布局，用我提供的真实材料替换模板中的标题、正文、组织名称、日期和联系信息。模板内示例数据不是业务事实，不得直接沿用。优先编辑已有原生图表的数据和原生表格的单元格，不将图表和表格转成图片。第 7 页图片区域用于放置与材料对应的图片，保留图片比例。内容增加时优先复制对应类型的内容页，按最终页数更新目录、章节编号和页码。不通过大幅缩小字号容纳过量文字。删除“模板示例”“请替换内容”“TEMPLATE”等模板提示，并处理所有未填充的占位内容。资料中没有的数据和事实不要编造，必要时标注“待补充”。

图片不足时可再追加：

> 优先使用我上传的图片；没有合适素材时，用简短文字或原生图表替代，最终 PPT 中不保留空白图片框。

需要讲者备注时可再追加：

> 每页补充适合口头讲解的讲者备注，备注区不保留模板示例说明，不把讲稿堆放到幻灯片正文中。

## 文件特点与使用边界

- 使用原生文字对象、标题/正文占位符、图片占位符、原生图表和原生表格，不是整页截图。
- 每份图表配有内嵌示例数据工作簿，图表中的数值均明确标记为示例。
- 字体为微软雅黑。其他设备缺少该字体时，显示可能发生替换。
- 已做文件结构、原生对象和页面渲染检查；尚未用这 5 份文件分别跑完真实模型填充任务。Agent 的实际填充效果仍取决于材料、模型及生成参数。
